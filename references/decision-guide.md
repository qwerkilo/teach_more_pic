# 组件选择决策指南

> 本文档是 `SKILL.md` 的参考附件。主工作流在 SKILL.md 中，此处只列选择矩阵。

**组件编号说明**：SKILL.md 组件索引表的编号（#1-26）是规范编号。磁盘文件编号（01-27，跳过 24）因历史重排与规范编号不一致，引用时以组件索引表为准。

**优先原则**：优先使用零依赖或轻量组件。ECharts (#24) 和 Three.js (#25) 需额外引入 `libs/` 文件，仅在 CSS/Tab/卡片等无法满足需求时才选用。

按内容类型选择最合适的组件。每课可从多个象限选取，形成丰富的视觉节奏。

## 三层选型策略

从简到繁，优先上层的轻量方案：

```
第一优先（零依赖）: 原生折叠/模态/幻灯片/Popover (#26a-d) + CSS 条形图 (#4) + CSS 时间线 (#3) + 角色卡片 (#2) + 数据卡片 (#12) + 标签组 (#17)
                         ↓ 需要交互
第二优先（CSS + JS 轻量）: Tab 面板 (#9) + 折叠分步 (#8) + 交互时间线 (#11) + 状态链 (#15) + 对比滑块 (#10) + 引文卡片 (#13) + 告警条 (#18)
                         ↓ 需要复杂数据处理
第三优先（需外部库）: ECharts (#24) + Three.js (#25)
```

## ECharts / Three.js 适用场景清单

这些组件有外部依赖成本，仅在以下场景使用：

| 组件 | 何时值得用 | 何时该避开 |
|---|---|---|
| ECharts 柱状图 (#24a) | 数据量 >8 类 / 需要动画排序 / 交互式下钻 | 静态 2-5 个数值 → 用 CSS 条形图 (#4) |
| ECharts 饼图 (#24b) | 需要交互式分离 / 数据动态变化 | 静态占比 → CSS 条形图 (#4) 的百分比条足够 |
| ECharts 折线图 (#24c) | 数据点 >6 / 需要悬停 tooltip / 平滑曲线 | ≤6 个数据点 → 交互式时间线 (#11) |
| ECharts 堆叠图 (#24d) | 多分类 + 时间序列交叉分析 | 少维度 → 对比表 (#22) |
| Three.js (#25) | 数据有天然三维属性（地理/力学/分子结构） | 任何可以通过 2D 表达的静态可视化 |
