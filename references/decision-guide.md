# 组件选择决策指南

> 本文档是 `SKILL.md` 的参考附件。主工作流在 SKILL.md 中，此处只列选择矩阵。

**组件编号说明**：SKILL.md 组件索引表的编号（#1-26）是规范编号。磁盘文件编号（01-27，跳过 24）因历史重排与规范编号不一致，引用时以组件索引表为准。

**风格策略**：优先使用 ECharts (#24) 交互式图表和 Three.js (#25) 3D 可视化提升课程品质。CSS 静态组件用于轻量装饰性场景。

按内容类型选择最合适的组件。每课可从多个象限选取，形成丰富的视觉节奏。

## ECharts + Three.js + D3.js 优先策略

每课至少应包含 1 个 ECharts / Three.js / D3.js 组件，以提升视觉品质：

- **ECharts 柱状图 (#24a)**：最通用的数据展示，适合对比、排名、分布
- **ECharts 饼图 (#24b)**：占比、份额、预算分配
- **ECharts 折线图 (#24c)**：趋势、增长、历史变化
- **ECharts 堆叠图 (#24d)**：多维度构成变化
- **Three.js 3D (#25)**：三维柱状图、地理数据、空间结构
- **D3.js 力导向图 (#27a)**：关系网络、组织结构、知识图谱
- **D3.js 旭日图 (#27b)**：多层占比、层次数据
- **D3.js 桑基图 (#27c)**：流量流向、转化路径

> 每课优先从 ECharts (#24)、Three.js (#25)、D3.js (#27) 中至少选 1 个作为核心视觉锚点，再搭配轻量组件完成其他内容。

### 跨库组合推荐

三个图表库不仅可选其一，也可以搭配使用发挥各自优势：

| 组合模式 | 数据层 | 渲染层 | 典型场景 |
|---|---|---|---|
| D3.js → Three.js | D3.js 计算布局（力导向/层次/地理投影） | Three.js 渲染 3D 场景 | 3D 力导向图、3D 旭日图、地理数据球体投影 |
| D3.js → ECharts | D3.js 数据聚合/筛选/转换 | ECharts 渲染标准图表 | 大数据量降采样后展示；自定义数据转换后喂给 ECharts |
| Three.js + ECharts | ECharts 2D 图表 | Three.js 3D 辅助场景 | 同一页面同时展示 2D 趋势图 + 3D 空间分布 |
| D3.js 纯数据处理 | D3.js 做数据格式转换、比例尺映射 | 其他 CSS/HTML 组件消费处理后的数据 | 用 d3-scale 生成色阶后渲染 CSS 热力图 |

> 组合示例：金融课程中 D3.js 计算投资组合相关性矩阵，Three.js 渲染为 3D 网络图；同时 ECharts 折线图展示各资产的历史走势。
