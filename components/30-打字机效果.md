### 30. 打字机效果（文本逐字输出）

关键引文或核心论断以逐字输出的方式呈现，增强视觉冲击力。

HTML 结构：
```html
<div class="tw-typewriter" data-anim="fade-up" data-text='"泡沫破裂时，恐慌才是真正的传染源。" — 2008 年金融危机亲历者' data-speed="60">
  <span class="tw-cursor">|</span>
</div>
```

使用规则：
- 适用场景：引文卡片（#13）、章节引语、关键数字页中的论断
- `data-text`：要逐字输出的文本（含引号标点）
- `data-speed`：每字间隔毫秒（默认 60）
- 文字用 `<span class="tw-cursor">` 闪烁光标收尾
- 每个页面最多 2 个打字机，多个会分散注意力

CSS：
```css
.tw-typewriter{font-size:1.1rem;line-height:1.7;color:var(--text,#1a1a1a);padding:1em 1.5em;background:var(--surface,#f5f0eb);border-radius:var(--radius,8px);border-left:3px solid var(--accent,#c0392b);margin:1.5em 0;min-height:2em;}
.tw-typewriter .tw-cursor{animation:tw-blink 0.8s step-end infinite;font-weight:100;color:var(--accent,#c0392b);margin-left:1px;}
@keyframes tw-blink{50%{opacity:0;}}
@media(prefers-reduced-motion:reduce){.tw-typewriter .tw-cursor{animation:none;}}
```

JS：
```html
<script>
// 打字机效果
(function(){if(!window.IntersectionObserver)return;
document.querySelectorAll('.tw-typewriter').forEach(function(el){var t=el.dataset.text||'',s=parseInt(el.dataset.speed)||60,c=el.querySelector('.tw-cursor');if(!t||!c)return;
var o=new IntersectionObserver(function(e){if(e[0].isIntersecting){o.unobserve(el);var i=0,h=setInterval(function(){c.before(document.createTextNode(t[i++]));if(i>=t.length){clearInterval(h);c.style.animation='tw-blink 1.5s step-end infinite';}},s);}},{threshold:0.5});o.observe(el);});})();
</script>
```

降级说明：
- **不支持 IntersectionObserver**：直接显示完整文本
- **JS 未加载**：容器为空（.tw-typewriter 只有闪烁光标）——需确保 `data-text` 也作为回退文本放在容器内
- **prefers-reduced-motion**：仅光标闪烁禁用，打字效果保留
