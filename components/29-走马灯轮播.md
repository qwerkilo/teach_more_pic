### 29. 走马灯/轮播（图片或卡片循环展示）

自动播放的图片/卡片轮播，支持箭头导航、点指示器和暂停悬停。

HTML 结构：
```html
<div class="cr-carousel" data-anim="fade-up">
  <div class="cr-track">
    <div class="cr-slide"><img src="https://picsum.photos/seed/a/800/400" alt="Slide 1"><div class="cr-caption">第一张：引言</div></div>
    <div class="cr-slide"><img src="https://picsum.photos/seed/b/800/400" alt="Slide 2"><div class="cr-caption">第二张：核心概念</div></div>
    <div class="cr-slide"><img src="https://picsum.photos/seed/c/800/400" alt="Slide 3"><div class="cr-caption">第三张：数据展示</div></div>
    <div class="cr-slide"><img src="https://picsum.photos/seed/d/800/400" alt="Slide 4"><div class="cr-caption">第四张：总结</div></div>
  </div>
  <button class="cr-prev" aria-label="上一张">‹</button>
  <button class="cr-next" aria-label="下一张">›</button>
  <div class="cr-dots"></div>
</div>
```

使用规则：
- 每张 slide 建议固定宽高比（图片用 `object-fit: cover`）
- 自动播放间隔 4 秒，悬停暂停
- 最少 2 张，最多 8 张
- 与数据卡片网格（#12）搭配时，使用卡片代替 `<img>`
- 竖屏则不用，因为轮播在窄屏上操作困难

CSS：
```css
.cr-carousel{position:relative;overflow:hidden;border-radius:var(--radius,8px);margin:1.5em 0;background:var(--surface,#f5f0eb);}
.cr-track{display:flex;transition:transform 0.5s cubic-bezier(0.4,0,0.2,1);will-change:transform;}
.cr-slide{min-width:100%;position:relative;}
.cr-slide img{width:100%;display:block;aspect-ratio:2/1;object-fit:cover;}
.cr-caption{position:absolute;bottom:0;left:0;right:0;padding:0.75em 1em;background:linear-gradient(transparent,rgba(0,0,0,0.7));color:#fff;font-size:var(--small-size,0.85rem);text-align:center;}
.cr-prev,.cr-next{position:absolute;top:50%;transform:translateY(-50%);background:rgba(0,0,0,0.5);color:#fff;border:none;font-size:1.5rem;width:2.2rem;height:2.2rem;border-radius:50%;cursor:pointer;z-index:2;opacity:0;transition:opacity 0.3s;line-height:2.2rem;text-align:center;}
.cr-carousel:hover .cr-prev,.cr-carousel:hover .cr-next{opacity:1;}
.cr-prev{left:0.75rem;}
.cr-next{right:0.75rem;}
.cr-dots{position:absolute;bottom:0.5rem;left:50%;transform:translateX(-50%);display:flex;gap:6px;z-index:2;}
.cr-dots span{width:8px;height:8px;border-radius:50%;background:rgba(255,255,255,0.5);cursor:pointer;transition:background 0.3s;}
.cr-dots span.active{background:#fff;transform:scale(1.3);}
@media(max-width:600px){.cr-prev,.cr-next{opacity:1;width:1.8rem;height:1.8rem;font-size:1.2rem;line-height:1.8rem;}}
```

JS：
```html
<script>
// 走马灯轮播
(function(){document.querySelectorAll('.cr-carousel').forEach(function(c){var t=c.querySelector('.cr-track'),s=t.querySelectorAll('.cr-slide'),d=c.querySelector('.cr-dots'),p=c.querySelector('.cr-prev'),n=c.querySelector('.cr-next'),i=0,to;
s.forEach(function(_,j){var dot=document.createElement('span');dot.addEventListener('click',function(){go(j);});d.appendChild(dot);});
function go(j){i=(j+s.length)%s.length;t.style.transform='translateX(-'+(i*100)+'%)';d.querySelectorAll('span').forEach(function(sp,k){sp.classList.toggle('active',k===i);});}
function next(){go(i+1);}
function prev(){go(i-1);}
if(n)n.addEventListener('click',next);
if(p)p.addEventListener('click',prev);
function play(){to=setInterval(next,4000);}
function stop(){clearInterval(to);}
c.addEventListener('mouseenter',stop);
c.addEventListener('mouseleave',play);
go(0);play();})})();
</script>
```

降级说明：
- **JS 未加载**：显示第一张图片，无轮播互动
- **窄屏**：箭头始终可见，dot 尺寸缩小
- **图片加载慢**：建议使用低分辨率占位图
